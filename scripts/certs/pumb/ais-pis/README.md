# PUMB AIS_PIS test key pair

Put the public PUMB Open Banking sandbox AIS_PIS test certificate and private key here.

Default names:

```txt
client.crt
client.key
```

The smoke-test also auto-detects `.crt`, `.cer`, `.pem` and `.key` files in this folder.

Official source: https://www.pumb.ua/en/open_api → Test Data and Certificates → AIS_PIS.
